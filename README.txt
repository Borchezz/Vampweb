# Bloodbar Для Windows

## Запуск

1. Распакуйте весь архив Bloodbar-Windows-x64.zip в любую папку.
2. Откройте Bloodbar.exe. Устанавливать Node.js, Git или зависимости не нужно.
3. Игра откроется в браузере по умолчанию. Интернет не нужен.
4. Оставьте консольное окно приложения открытым на время игры. Чтобы остановить сервер, закройте его или нажмите Ctrl+C. Закрытие вкладки браузера само по себе сервер не останавливает.

Требуется Windows 10/11 x64 и современный браузер. Не переносите EXE отдельно от папки app. Исполняемый файл пока не подписан: Windows SmartScreen может показать предупреждение. Не отключайте защиту Windows; запускайте только архив, полученный от разработчика.

Если браузер не открылся автоматически, скопируйте адрес из окна приложения. Сервер слушает только 127.0.0.1, не доступен другим устройствам и не требует открытия порта в роутере. По умолчанию используется 4183; при занятости выбирается следующий свободный порт, который запоминается. Не запускайте несколько копий одновременно: они используют общую папку сохранений.

## Данные

В архив входит опубликованный набор профилей из репозитория. Личные неопубликованные данные разработчика в архив не включаются.

Кнопка «Сохранить» сохраняет профиль в `%LOCALAPPDATA%\Bloodbar\editor-workspace`. Эта папка сохраняется при замене архива новой версией. Резервную копию делайте при закрытом приложении. Публикация в GitLab в автономной версии отключена; вместо попыток соединения показывается сообщение.

Браузерные черновики остаются в хранилище используемого браузера и зависят от адреса/порта. Не считайте их резервной копией: сохраняйте важные изменения кнопкой «Сохранить». Перенос архива на другой компьютер не переносит пользовательские данные. Сборка не добавляет отдельного механизма сохранения текущего прохождения.

Для изолированной тестовой копии можно задать переменную окружения BLOODBAR_DATA_DIR. Для запуска без открытия вкладки используйте `Bloodbar.exe --no-open`.

## Сборка Разработчиком

В корне репозитория, с Node.js 20 или новее:

```sh
npm ci --prefer-offline
npm run build:windows
```

Результат: `dist/Bloodbar-Windows-x64.zip` и контрольная сумма `.sha256`. Сборщик работает на macOS, Linux и Windows x64, скачивает официальный Node.js 26.8.2 для Windows и машины сборки, проверяет SHA256, добавляет лицензию Node.js и создаёт Node SEA launcher встроенной командой `--build-sea`. На macOS/Linux требуется стандартный `tar`. Отдельная установка Node нужна только на машине сборки. Папка dist не коммитится.

Для проверки серверной части пакета на машине сборки:

```sh
node scripts/portable-launcher.cjs dist/Bloodbar --no-open
```

Кросс-сборка не заменяет проверку на Windows: перед передачей широкой аудитории проверьте двойной клик, открытие браузера, сохранение профиля, повторный запуск и закрытие процесса на Windows 10/11.
