# Проверки ночных добавок

## Автоматические проверки правил

Из корня проекта с установленным Node.js:

```bash
npm --prefix app test
```

Зависимости устанавливать не требуется: используется встроенный `node:test`.

Проверяются каталог, бесконечность барных и расход медицинских добавок, миграция старого профиля, уникальность четырёх ячеек, хранение по профилям и правила двух слотов коктейля.

## Браузерные сценарии

`nighttime-additives.browser.js` экспортирует проверки для запуска в консоли браузера или через автоматизацию. **Только в изолированном тестовом браузере/профиле:** сценарии меняют localStorage этого браузера и настройки диапазона компонентов. Не запускать поверх личных черновиков.

На чистом тестовом origin открыть `?mode=nighttime`, дождаться загрузки и выполнить:

```js
const tests = await import('/tests/nighttime-additives.browser.js');
await tests.testBarAdditiveShelf();
tests.testAdditiveCategoryEditor();
await tests.testBarAdditivePreparation();
tests.testBarShelfEditorReachable();
```

Последний сценарий оставляет редактор открытым. Первый требует первоначально пустую барную полку; не выполнять второй раз без отдельного тестового origin либо осознанного сброса только тестовых ячеек.

Дополнительно проверить:

- после перезагрузки страницы выбранные барные добавки остались;
- при 0 случайных конечных компонентах барная полка всё равно доступна;
- после переключения профиля компонентов полки не смешиваются;
- при выключенном ограничении ресурсов медицинские компоненты работают как раньше;
- в `?mode=full` проходит `testBarAdditiveShelf()` на изначально пустой полке; ночная поверхность в этом режиме скрыта существующим дизайном;
- `?mode=daytime` загружается без ошибок;
- на узком экране нет горизонтального переполнения, кнопки очистки не перекрыты редактором.

Для смены выбранной добавки в игре: включить «Редактор», прокрутить до барной полки, нажать крестик на нужной ячейке и выбрать новую добавку. В standalone-ночном режиме панель редактора расположена слева, а на узком экране ограничена по высоте, чтобы не закрывать полку.

Барные ячейки хранятся отдельно от конечных запасов по ключу `bloodbar-nighttime-bar-additive-slots:<componentProfileId>`. Это browser storage, а не JSON-профиль дневного редактора и не сохранение Git.
